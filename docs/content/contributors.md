# Contributors

We welcome contributions from the community! Whether you've found a bug, have a feature request, or want to contribute code, we're happy to receive your input.

### Submit Pull Requests

We accept pull requests! Before submitting:

1. Fork the relevant provider repository
2. Create a feature branch
3. Make your changes following our coding standards
4. Submit a PR with a clear description

### Feedback

General feedback or questions about the provider ecosystem can be opened as issues in the [crossplane-providers](https://github.com/rossigee/crossplane-providers/issues) meta-repo.

## Developer Requirements

When contributing code, please ensure:

- Go code follows standard Go conventions
- CRDs are properly defined with meaningful descriptions
- Controllers implement the Crossplane patterns
- Tests are included for new functionality
- Documentation is updated for any user-facing changes
