# Crossplane Providers

A collection of lean, focused Crossplane providers designed for efficiency and operational simplicity.

## Quick Links

- **[Providers](/crossplane-providers/providers/)** - All providers with versions
- **[Standards](/crossplane-providers/standards/)** - Platform requirements and conventions

## Overview

This meta-repo tracks 20 Crossplane providers with a focus on:
- Native Go implementations (no Terraform/Upjet)
- Crossplane v2.5+ compatibility
- Minimal, efficient binaries
- Clean Kubernetes integration
